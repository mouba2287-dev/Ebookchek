# Prompt - Étape 4 : Paiement Mobile Money + Mode Validation

## Context & Product Mission
Ebook Check serves West African creators with price sensitivity in FCFA via Mobile Money (FedaPay / Kkiapay).

- **Design System Rules:** Ivory background (`#FAF3E7`), Marigold CTA (`#F2A93B`), Warm Coral (`#E85C4A`), Success (`#2F9E68`). Typography: Fraunces & Public/Work Sans.

## Task Description
Implement Step 4 of the development priorities: **Paiement Mobile Money + Mode Validation**.

### Deliverables & Requirements:
1. **Pricing Page (`/tarifs`):**
   - Clear comparative pricing model: Free tier (1 report/month) vs Paid detailed report vs Monthly subscription.
   - Integrated Mobile Money payment flow (FedaPay / Kkiapay) directly within page without complicated redirects.
   - Prices listed in FCFA.

2. **Validation Mode (`/valider`):**
   - Form inputs: Subject/topic, target audience, intended price.
   - Viability score calculation, suggested differentiating titles, recommended price range.
   - Server-side validation of inputs.
